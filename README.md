# TexCom (web)

TexCom is a text-based AAC app: type or choose phrases and it speaks them aloud.

This repository publishes the web version at **https://sensoryapphouse.github.io/texcom/**

- `index.html` — the app
- `companion.html` — the page a conversation partner opens from a TexCom link or QR code
- `partner.html` — a second screen showing the last phrase, very large

The iPhone, iPad and Mac apps use the same files. Source of truth: the `Content` folder of the
TexCom Webview project.
